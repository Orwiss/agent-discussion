  • ma_11 Gambino, Fox & Ratan (2020) Building a Stronger CASA — CASA 패러다임 이론 확장 논문이지 리뷰가 아님

3. VR Ideation — 리뷰 2편

vri_03Virtual Brainstorming and CreativityGong et al., ICED 2021

RQ: VR×브레인스토밍×창의성을 다룬 실증 연구의 trend·measure·카테고리 분포는 어떠한가

검색 전략: Scopus · Web of Science · EBSCO · IEEE Xplore · ACM Digital Library 5개 DB

기간: 2013–2020 (8년)

키워드: "virtual reality" + "brainstorming" / "creativity" / "ideation" 조합

포함 기준: 실험 기반 논문만 (case study·시스템 데모 제외). 데스크탑 VR / Second Life / HMD 모두 포함

최종 N: 15편

분류 차원(taxonomy): 4 카테고리 — (1) Avatar 효과, (2) Environment 효과, (3) Interface 디자인, (4) Application 도메인. Creativity measure는 산출 기반(fluency·originality·uniqueness·novelty) vs 시스템 기반(usability·flow)

핵심 발견:

  • 4 카테고리가 비슷한 비중. Interface 단독 연구는 1편뿐
  • Creativity measure: 산출 카운팅이 절반, 나머지는 usability/flow 같은 보조 지표
  • 매체 분포: 절반 이상이 비-HMD(데스크탑/Second Life), HMD는 소수
  • Creative avatar · social identity cue · topic priming이 창의성에 긍정적 영향

한계: HMD 기반 immersive VR 연구가 부족, 표본이 공대생에 편중, 표정·신체 표현이 미반영, immersion level과 창의성의 관계가 미해결

Future work: 표정 자동 생성, 다양한 분야 사용자, 회사/조직 단위 social identity까지 확장 필요

사용자 연구와의 관계: "HMD + AI agent + 브레인스토밍" 교차점이 비어 있다는 점 확인. 사용자 연구가 정확히 그 공백을 채움

vri_04Design-thinking Skill Enhancement in VRLyu et al., Frontiers in VR 2023

RQ: VR이 design-thinking skill 향상에 어떻게 적용되어 왔나

검색 전략: Scopus · Web of Science · ACM Digital Library 3개 DB

기간: ~2023까지 (cutoff 명시 보수적, 약 10년치)

키워드: "virtual reality" + "design thinking" / "design education" / "ideation"

포함 기준: design-thinking 또는 그 부분 단계(empathize/define/ideate/prototype/test) 다룬 VR 연구

최종 N: 54편

분류 차원: 5-outline thematic analysis — (1) Adapting (어떻게 VR로 적응), (2) Scope (범위), (3) Conditions (조건), (4) Process (프로세스), (5) Integration (통합). 추가로 VR type · design-thinking 단계 · 참가자 · 출판 분야로 cross-tabulation

핵심 발견:

  • 매체 분포: HMD 23편 ≫ CAVE 3편 > 둘 다 사용 1편. 비-immersive(데스크탑/프로젝션)도 상당수
  • 단계 분포: 대부분 prototyping/ideating에 집중. empathize/define 활용은 적음
  • 인지·체화(embodiment) 측면의 학습 효과는 일관되게 보고됨
  • AI와 결합한 연구는 거의 없음 — 명시적 갭

한계: 표준화된 design-thinking skill 평가 도구의 부재, VR 멀미·인터페이스 한계가 반복 지적

Future work: "AI/IoT 같은 신기술과의 통합 연구가 필요"하다고 결론에서 명시

사용자 연구와의 관계: 저자가 직접 "AI 통합 future work"을 적시 — 사용자 연구의 VR + 멀티에이전트 LLM 결합이 이 처방을 그대로 실증함

4. VR Agent/Avatar — 리뷰 2편

vra_10Integrating Personality into Digital HumansBrito et al., 2025

RQ: LLM 기반 가상휴먼(digital human)에 personality를 부여하는 방법과 평가 방법론의 현황은

검색 전략: 학술 DB 다중(구체적 DB 명시는 본문에서 다양) — IEEE/ACM/arXiv 위주

기간: 주로 2022–2025 LLM 부상 이후

키워드: "digital human" / "virtual human" / "embodied agent" + "personality" / "Big Five" / "persona"

포함 기준: LLM 기반 + 가상휴먼/임바디드 에이전트의 personality 부여를 다룬 연구

최종 N: 본문 명시는 약 30~40편 추정 (논문에서 명시적 카운트 단정 어려움)

분류 차원: (1) Personality 부여 방법 — zero-shot prompting / few-shot / fine-tuning, (2) 평가 방법 — BFI(Big Five Inventory) 자동평가, Likert 자기보고, LLM-as-judge, (3) 출력 modality — 텍스트 / 표정·제스처(멀티모달)

핵심 발견:

  • 평가 방법론이 정성·정량(BFI/Likert)·LLM-as-judge로 혼재되어 비교 불가
  • 멀티모달 출력(표정·제스처) 평가의 표준이 부재
  • 연산 비용·지연이 실시간 임바디드 시나리오의 핵심 병목

한계: 표준화된 평가 프레임 부재, 연산 비용, 지연. 단일 에이전트 중심

Future work: 표준 평가 벤치마크, 멀티모달 통합 평가

사용자 연구와의 관계: 단일 에이전트의 personality 표현이 주제이고 멀티 에이전트 토론·상호인지는 거의 다루지 않음. 사용자 연구에서 에이전트 페르소나를 설계할 때 방법론적 참고지, 사용자 연구의 핵심 갭(에이전트 간 상호인지)을 다루는 리뷰는 아님

vra_11How LLMs are Shaping the Future of VRÖzkaya et al., 2025

RQ: LLM이 VR 게임/응용에서 어떤 영역에 적용되고 있고, 한계는 무엇인가

검색 전략: 학술 DB(IEEE Xplore, ACM DL, Scopus) + 산업 keynote/whitepaper 보조

기간: 2018–2025 (8년) — LLM 부상 전후 모두 포함

키워드: "LLM" / "large language model" + "virtual reality" / "VR" / "NPC" / "game"

포함 기준: LLM이 VR/XR 게임 시스템에 통합된 사례. NPC, 내러티브 생성, 접근성, 게임마스터링 모두 포함

최종 N: 62편

분류 차원: 적용 영역 — (1) NPC 적응성, (2) 내러티브 생성, (3) 접근성(accessibility), (4) 게임마스터링, (5) 멀티에이전트 조정(소수)

핵심 발견:

  • LLM이 NPC 적응성·내러티브·접근성에서 유망함
  • 한계: 실시간 성능, 메모리(장기 대화), 일관성, 윤리, 다중에이전트 조정의 자원 부담
  • "멀티에이전트 brainstorming in VR"을 직접 언급한 거의 유일한 항목 — Lin et al. VR brainstorming 시스템이 한 줄로 짚힘

한계: 실시간 멀티에이전트 추론 비용, 장기 대화 유지, 멀티에이전트 가상세계의 안전·일관성

Future work: 실시간 멀티에이전트 추론 최적화 + VR 협업 시나리오 안전·일관성 — 사용자 연구의 방향과 정면 일치

사용자 연구와의 관계: 본 컬렉션에서 "멀티에이전트 brainstorming in VR"을 직접 언급한 거의 유일한 리뷰. 단 본인이 한 연구가 아니라 리뷰 차원의 인용. 사용자 연구가 이 인용된 공백을 직접 메우는 위치

5. Multi-Agent Discussion (신규 컬렉션) — 리뷰 5편

2024–2026 기간 LLM 기반 멀티에이전트 시스템(MAS) 분야의 리뷰가 폭발적으로 늘었다. 이 컬렉션에는 일반 MAS 서베이 4편 + 소프트웨어공학 특화 1편이 들어 있다.

mad_01Multi-Agent Collaboration Mechanisms: A Survey of LLMsTran et al., 2025

저자: Khanh-Tung Tran, Dung Dao, Minh-Duong Nguyen, Quoc-Viet Pham, Barry O'Sullivan, Hoang D. Nguyen (UCC, Trinity College Dublin 등)

DOI: 10.48550/arXiv.2501.06322 · arxiv preprint (2025-01)

RQ: LLM 기반 multi-agent 시스템의 collaboration mechanism을 어떻게 체계적으로 분류·이해할 수 있는가

검색 전략: arXiv, ACL Anthology, AAAI, NeurIPS, ICML 위주 — 명시적 systematic 프로토콜은 약식

기간: 2022–2024 (LLM 부상 이후)

포함 기준: LLM-MAS의 collaboration mechanism을 다룬 시스템/이론 논문

분류 차원(5-D taxonomy — 이 리뷰의 핵심 기여):

  • Actors — 누가 (역할/페르소나/도구)
  • Interaction types — cooperation / competition / coopetition
  • Organizational structures — peer-to-peer / centralized / distributed
  • Strategies — role-based / model-based
  • Coordination protocols — 누가 언제 발화하는가

적용 도메인: 네트워킹, 산업 자동화, QA, 사회적 컨텍스트

핵심 발견 + Future work: "artificial collective intelligence"를 향한 challenge — 평가 표준화·통합 벤치마크·확장성

사용자 연구와의 관계: 사용자 연구의 토론 조건(에이전트 간 상호인지)을 interaction type = cooperation + organizational structure = peer-to-peer + coordination protocol = mutual awareness로 매핑할 수 있게 해주는 분류 어휘 제공

mad_02Creativity in LLM-based Multi-Agent Systems: A SurveyLin et al., EMNLP 2025 Main

저자: Yi-Cheng Lin, Kang-Chieh Chen, Zhe-Yan Li, Tzu-Heng Wu, Tzu-Hsuan Wu, Kuan-Yu Chen, Hung-yi Lee, Yun-Nung Chen (NTU)

DOI: 10.48550/arXiv.2505.21116 · EMNLP 2025 Main (aclanthology.org/2025.emnlp-main.1403)

RQ: LLM 기반 multi-agent system이 creative output을 어떻게 생성하는가 — 인간-AI 공동 창의의 분류와 갭은

검색 전략: arXiv + EMNLP/ACL/NAACL/CHI/CVPR 위주

기간: 2022–2025

포함 기준: LLM-MAS가 텍스트·이미지·코드 등 creative artifact를 생성하는 연구

분류 차원:

  • (1) Agent proactivity — reactive vs proactive
  • (2) Persona design — diversity, specialization
  • (3) Generation methods — divergent exploration, iterative refinement, collaborative synthesis
  • (4) Evaluation metrics — automatic vs human vs LLM-as-judge

핵심 발견:

  • Divergent exploration(다양한 페르소나로 발산)이 가장 흔한 전략
  • Iterative refinement(critique-revise 루프)가 quality 향상에 기여
  • 인간 사용자가 끼는 user study가 매우 드물다 — LLM-as-judge 또는 자동평가에 편중

갭으로 명시한 것: "inconsistent evaluation standards · insufficient bias mitigation · coordination conflicts · lack of unified benchmarks"

사용자 연구와의 관계: 이 서베이의 갭 진단이 사용자 연구의 동기와 정확히 일치. 특히 "user study 부재 + 평가 표준화 부재"가 사용자 연구가 CSI로 메우는 자리. 단, Lin et al.은 텍스트·이미지 생성 위주이지 디자인 ideation은 아님
